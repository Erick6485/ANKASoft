### **Terminal 1 - Backend:**


```powershell
cd frontend
npm run dev
```

**Login:** `admin` / `admin123`

### **1. Dashboard** → `/dashboard`
- 4 Cards de KPIs
- Productos destacados
- Gráfico de ventas
- Alertas de stock
- Chatbot flotante

### **2. Analytics** → `/analytics` (📊 en sidebar)
- **NUEVO** Filtros: Mes, Categoría, Género, Límite
- Tabla de productos más vendidos
- Grid de rotación por tallas
- Tips para demo

### **3. Patrones de Compra** → `/patrones` (🧠 en sidebar)
- Reglas de asociación (Apriori)
- Búsqueda de recomendaciones cruzadas
- Estadísticas de patrones
- Sugerencias de acción

## 🎬 **RUTA DE NAVEGACIÓN PARA DEMO**

```
1. Login (admin/admin123)
   ↓
2. Dashboard → Ver resumen ejecutivo
   ↓
3. Clic en 📊 (Analytics)
   - Aplicar filtro: Categoría = "JEANS TERMINADOS"
   - Ver tabla de resultados
   - Ver rotación de tallas
   ↓
4. Volver al Dashboard
   ↓
5. Clic en 🧠 (Patrones de Compra)
   - Ver reglas descubiertas
   - Buscar: "CAMISAS"
   - Ver recomendaciones
   ↓
6. Volver al Dashboard
```

**Tiempo total:** 5-8 minutos
