# Configuración de Variables de Entorno para Vercel

Cuando despliegues en Vercel, agrega estas variables de entorno:

## Variables de Entorno:

```
VITE_API_URL=https://retail-analytics-api.onrender.com
VITE_API_KEY=retail_hackaton_2025_fup
```

## Pasos en Vercel:

1. Ve a tu proyecto en Vercel Dashboard
2. Settings → Environment Variables
3. Agrega las variables de arriba
4. Redeploy el proyecto

## Actualizar URL del Backend:

Una vez que tengas tu backend desplegado en Render, copia la URL (ejemplo: `https://retail-analytics-api-xxxxx.onrender.com`) y actualízala en Vercel.
